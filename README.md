# Live Incident Response – Proyecto Final

## Descripción

Este repositorio contiene el informe técnico correspondiente al Proyecto Final de **Live Incident Response** desarrollado para el curso de Ciberseguridad de 4Geeks Academy.

El trabajo documenta el análisis realizado sobre un servidor Linux comprometido utilizando una metodología de **Live Incident Response**, con el objetivo de identificar evidencias, reconstruir el incidente y elaborar recomendaciones de seguridad sin afectar la disponibilidad del sistema.

## Contenido

- 📄 Informe técnico en formato PDF.
- 📄 Informe técnico en formato DOCX.

Las capturas de pantalla y evidencias utilizadas durante la investigación se encuentran incorporadas dentro del informe.

## Temas abordados

- Live Incident Response
- Análisis de usuarios y privilegios
- Revisión de tareas programadas (Cron)
- Análisis de registros de autenticación
- Identificación de mecanismos de persistencia
- Correlación de evidencias
- Reconstrucción del incidente
- Recomendaciones de seguridad
